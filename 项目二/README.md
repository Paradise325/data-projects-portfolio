# 智能车牌识别系统

## 项目描述
面向智慧城市交通场景，研发端边云协同的智能车牌识别数据处理系统，覆盖图像数据采集、预处理、特征提取到识别服务输出的全链路，支撑停车场、卡口等多场景的车辆身份识别与交通数据上报。针对边缘低算力设备完成模型轻量化与性能优化，通过多帧投票机制提升复杂场景识别准确率。

## 技术栈
C/C++、Python、多线程并发编程、内存池管理、图像超分辨率预处理、EasyOCR、Flask API服务、边缘计算轻量化、日志监控体系

## 数据集说明
本项目使用 **CCPD2020 中国车牌数据集** 进行训练与测试，该数据集为学术开源数据集，覆盖模糊、遮挡、夜间、倾斜等多种异常场景。
> 注意：由于数据集文件体积较大，**并未上传至 GitHub**，本地使用时放置路径为 `data/CCPD2020/`，也可在代码中配置本地绝对路径。
